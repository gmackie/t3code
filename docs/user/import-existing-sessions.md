# Import existing projects and sessions

The project and session import wizard can bring existing Claude Code, Codex, and Grok Build work into T3 Code while preserving conversation history.

1. Open **Settings → Beta**.
2. Select **Open import wizard** under **Project and session import**.
3. Enter a folder to scan. The default is your home folder; you can choose a workspace such as `/Volumes/dev` instead.
4. Select the Git projects to review.
5. Select the provider sessions to import.

Projects and sessions are selected by default. Existing T3 Code projects and previously imported sessions are reused rather than duplicated.

Folder browsing is available in the desktop client. When connected remotely, enter a path on the environment host directly in the scan field.
