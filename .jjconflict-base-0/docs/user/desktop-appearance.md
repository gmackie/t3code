# Desktop appearance

The macOS desktop app can make every T3 Code window translucent, including the main app,
previews, sign-in popups, and connecting windows.

1. Open **Settings**.
2. Select **Appearance**.
3. Adjust **Window opacity**.

This is separate from **Glass opacity**. Glass opacity changes the material used by menus,
dialogs, and the composer inside T3 Code. Window opacity changes the whole native window so the
desktop behind T3 Code can show through. Set it to 100% to return to an opaque window.

The setting is local to the macOS desktop client. Web browsers, Windows, Linux, and T3 Code Mobile
keep their normal window treatment.
